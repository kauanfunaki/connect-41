# Fiscal integrado ao SPED

As telas fiscais usam exclusivamente a integração SPED Generator do escritório. Sem integração configurada ou com falha de conexão, apresentam indisponibilidade. A operação não alterna para o cenário local.

Consulte o [guia EFD](EFD-CONNECT.md), o [repasse para o Kauan](EFD-CONTRATO-KAUAN.md) e o contrato oficial `docs/API-CONNECT.md` do projeto SPED para configuração, escopo e implantação.
